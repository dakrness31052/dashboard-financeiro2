# Dashboard Financeiro - Visão por Sede & Consolidado (2026)

Repositório contendo o novo painel interativo de controle financeiro interno, permitindo navegação separada por unidade (Água Verde, Portão e Sede 01 / Praia Brava) e a junção consolidada no caixa geral com o painel dos sócios.

## 📊 Estrutura de Navegação do Dashboard
1. **Consolidado Geral:** Visão macro unindo Faturamento Total, Resultado Operacional de todas as sedes, Painel de Sócios e Lucro Líquido Final.
2. **Sede Água Verde:** Faturamento, Custos Fixos, Custos Variáveis e Lucro da Unidade.
3. **Sede Portão:** Faturamento, Custos Fixos, Custos Variáveis e Lucro da Unidade.
4. **Sede 01 (Praia Brava):** Ponto de equilíbrio e receita constante da sede 01.
5. **Painel dos Sócios:** Evolução das retiradas/despesas individuais de Marlon e Dani.

## 🚀 Como Executar ou Visualizar
- **Online:** Acesse a URL do GitHub Pages do repositório.
- **Local:** Abra o arquivo `index.html` em qualquer navegador web moderno.
